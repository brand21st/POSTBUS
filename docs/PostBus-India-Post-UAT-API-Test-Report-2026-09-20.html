8. Booking — BLOCKED

Booking requires a pickup/drop-off office that satisfies delivery_office_flag = true and office_type_code != BPO. That data was not available from UAT pincode APIs.

  • POST /process-articles/{customerId} was not called.
  • Bulk booking was not called.
  • UAT AWB range ET21433001XIN–ET21434000XIN was not used.
  • No real or production shipment was created.

13. Issues for CEPT / India Post (sandbox)

  1. Pin Code Search HTTP 500 on /v1/pincode-search for 570001, 400001 and 110001. Blocks booking UAT because office_id cannot be obtained.
  2. GET /v1/details?pincode=… returns 404 Route not found. Please confirm the live UAT pincode path.
  3. Event download POST /v1/event/download returns 204 empty (document expects XML).
  4. Tracking path: /tracking/bulk is 404; /v1/tracking/bulk is 200. Please confirm /v1 is required on all resources.
  5. 24/48 tariff and token-refresh URLs are unpublished ([Link] only) and were not guessed.
